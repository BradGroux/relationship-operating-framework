# Decisions

Decision records explain material choices about the framework's meaning,
authority, or adopted Commons release. They preserve rationale and authorize
corresponding canonical edits; they are not an independent normative layer or a
log of routine edits and project-management activity.

## Accepted decisions

- [0001: Adopt Open Framework Commons v1.1.0](0001-adopt-open-framework-commons-v1.1.0.md)

The version 1.0.0 issues, governance baseline, changelog, and review records
remain the authoritative history of the initial release. This directory does
not reconstruct decisions retrospectively.

Use the [decision template](template.md) for a new proposed record.

An accepted decision remains the rationale for its corresponding canonical
language until another accepted decision supersedes it. If a decision and the
canonical framework appear to conflict, maintainers must resolve the mismatch
in the canonical document rather than ask practitioners to infer a rule from
the decision record.
