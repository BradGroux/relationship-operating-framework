# 0001: Adopt Open Framework Commons v1.1.0

- **Status:** Accepted
- **Date:** 2026-08-22
- **Decision owner:** Founding steward
- **Release:** 1.1.0

## Context

Relationship version 1.0.0 adopted Open Framework Commons v1.0.0 at exact
release commit `a0f0d384e9010a65d1a21a324b4c912433d5e031`.

Commons v1.1.0 recognizes Focus Operating Framework as the fifth independent
product in Commons scope, corrects Commons review provenance, and adds bounded
repository-stewardship surfaces. The shared principles and boundaries are
unchanged. Commons explicitly leaves each product responsible for deciding
whether and when to adopt a later release.

The annotated Commons `v1.1.0` tag object
`79e5f06dab46f262cad1d1daf7840e683ffc3880` peels to release commit
`f25a2b89b4aed95984fd235e2e229efe52c125d8`.

## Options

1. Retain Commons v1.0.0. This would preserve a valid adoption but leave current
   Relationship guidance on the earlier ecosystem scope.
2. Adopt Commons v1.1.0 exactly. This would recognize the current shared scope
   without importing another product's method or changing Relationship practice.
3. Adopt with a deviation. No conflict or Relationship-specific need justifies
   a deviation.

## Decision

Adopt Open Framework Commons v1.1.0 exactly at commit
`f25a2b89b4aed95984fd235e2e229efe52c125d8`, with no deviations.

Keep Relationship independent. Commons owns shared principles and ecosystem
boundaries. Relationship continues to own its people-first stewardship method,
terminology, examples, evidence, governance, and releases. Focus recognition
does not import Focus guidance, and this adoption does not import Influence's
contribution or community-growth method.

## Consequences

- Current Relationship authority and contribution surfaces point to Commons
  v1.1.0 and its exact peeled commit.
- Historical v1.0.0 release and review records remain unchanged.
- Relationship's method, agent limits, human ownership of external action, and
  unresolved proposals remain unchanged.
- A future Commons release still requires a separate Relationship adoption
  decision.
- No dissent or unresolved deviation is recorded for this adoption.
