# Security and privacy

## Purpose

This repository contains documentation, but contributions and examples can
still expose credentials, private relationship context, personal data,
confidential material, unsafe automation ideas, or security-sensitive details.
Report those concerns privately.

Framework disagreements, ordinary corrections, and non-sensitive proposals
belong in public issues. Sensitive conduct reports follow the private path below
even when they are not software vulnerabilities.

## Supported versions

The latest published release and the current `main` branch receive security and
privacy corrections. Older documentation releases may be corrected only when a
material risk justifies a new release or explicit notice.

## Report privately

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/BradGroux/relationship-operating-framework/security/advisories/new>

Include only what is necessary to understand and contain the concern:

- the affected public path, release, or behavior;
- the type and likely impact of exposure;
- safe reproduction or confirmation steps, if applicable;
- whether the material is already public; and
- the reporter's preferred way to receive a response through GitHub.

Do not send credentials, raw private messages, full contact exports, unrelated
personal history, exploit payloads against third parties, or more sensitive data
than the report needs. Redact first. If safe private reporting is unavailable,
do not publish the sensitive material; open a minimal public issue asking the
steward to restore a private contact path.

## Response

The founding steward or a designated responder will:

1. acknowledge the report through the private channel;
2. limit access and preserve only necessary evidence;
3. assess affected files, releases, people, and downstream copies;
4. remove or contain exposed material when authorized;
5. prepare a correction and disclosure proportionate to the risk;
6. avoid repeating sensitive details in commits, issues, reviews, or release
   notes; and
7. record remaining limitations honestly.

This process does not promise a fixed response time or replace emergency,
legal, employment, safeguarding, privacy, or law-enforcement channels.
