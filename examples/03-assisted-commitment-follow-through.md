# Assisted commitment follow-through

- **Status:** Illustrative
- **Provenance:** Fictional
- **Review limit:** Documentation and framework alignment only; not a tested
  agent workflow, privacy control, or operational specification

## Stewardship question

How may an agent help a team notice missed commitments without gaining authority
to score people, infer permission, or send messages?

## Fictional context

A community workshop team asks an agent to review authorized project notes for
unresolved promises. The agent surfaces:

- a possible promise to send an edited resource to facilitator Sam;
- a suggestion to follow up with every attendee who has not responded; and
- an old note showing that attendee Lee asked not to receive further messages.

The notes contain contradictions, and the agent assigns high confidence to the
batch follow-up suggestion.

## Applying the framework

### Treat the output as a prompt for review

The team does not treat the agent's confidence as truth. A named human steward
checks the original workshop notes, approved communication scope, and source of
each possible commitment.

### Confirm the commitment

The source shows that a team member explicitly promised Sam the edited resource.
The team assigns a human owner to complete or renegotiate that commitment before
making any new request.

### Reject inferred permission

No source authorizes a message to every attendee. Non-response is not a
stewardship need or consent. The human steward rejects the batch suggestion.

### Carry the boundary forward

Lee's do-not-contact decision remains controlling. The team corrects any copy
that omits it and restricts retained context to what is needed to prevent future
unwanted contact.

### Keep external action human-owned

The agent may prepare a private checklist and draft a message to Sam. A human
must review the exact source, recipient, message, attachment, commitment, and
channel before deciding whether to send. The agent cannot queue, schedule,
retry, or transmit it.

## Where the example stops

The example does not claim that the message is sent, Sam accepts the resource,
or the team improves a relationship. It demonstrates the difference between
assistance and authority.
